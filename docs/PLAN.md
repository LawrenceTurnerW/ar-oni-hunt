# 計画メモ

## 解決したい体験

「現実世界を舞台に、AI 鬼から逃げながら AR アイテムを集める」体験を作る。スマホをかざすと鬼の姿とアイテムが見える、ソロで遊べる WebAR ゲーム。

---

## 1. ゲーム設計（ソロモード / アイテム回収型）

### 対象プラットフォーム

**Android Chrome のみ**（iOS は対象外。WebAR の挙動差吸収コストを削減）。

### コンセプト

公園や広場で、プレイヤーがゲーム開始時に GPS でフィールドを定義し、その中に AR アイテムが配置される。AI 鬼が徘徊しており、捕まらないように全アイテムを回収すればクリア。

### プレイヤー体験のフロー

1. **フィールド設定**: プレイヤーがゲーム開始時に多角形でフィールドを定義（フィールドの頂点を順番にタップで指定、最低 3 点）。多角形が難しければ「中心 + 半径」の円でフォールバック
2. **道路データ取得**: フィールドの bounding box で OpenStreetMap (Overpass API) から `footway/path/pedestrian/residential` のみを取得し、グラフを構築
3. **アイテム配置**: 道沿い（OSM path の ±5m 範囲）に N 個のアイテムを自動配置
4. **鬼の出現**: AI 鬼が 1 体、道路グラフ上のランダム node からスタート
5. **プレイ**: スマホをかざしてアイテム/鬼を視認、走って集める/逃げる
6. **結果**: 全アイテム回収でクリア、捕獲されるとゲームオーバー。クリア時はスコア（残り時間 × 残り体力 × アイテム数）を演出付きで表示

### アイテム回収

- アイテムから半径 **7m** 以内に入ると AR で表示される
- スマホをかざしてアイテムを画面中央のレチクルに入れ、タップで回収
- 回収アイテム種類（MVP は 1 種類: お札）
- 回収時にスコア加算（基本点 + 経過時間ボーナス）+ パーティクル演出
- アイテムは **OSM の道路グラフ近傍に配置** されるので、車道に立ち入らずに歩道から回収できる

### AI 鬼の挙動

**状態マシン**: `Patrol` → `Detect` → `Chase` → `Catch` / `Return to patrol`

- **道路グラフ上のみを移動**（OSM `footway/path/pedestrian/residential`）。グラフ取得失敗 or 道が無いフィールドでは「フィールド内ランダム walk」にフォールバック
- **Patrol**: グラフのランダム node を目的地に選び、最短経路で向かう（速度 ~3 km/h = 徒歩遅め）
- **Detect**: プレイヤーとの GPS 距離が **15m 以内** で「発見」状態に。視覚的な警告（画面赤フラッシュ、振動）
- **Chase**: 発見後はプレイヤーに最も近い node を目的地に切り替えて追跡。速度 +20%（早歩き ~4 km/h）
- **Catch**: 距離 **5m 以内** で捕獲、ゲームオーバー
- **Return to patrol**: プレイヤーが鬼から 20m 以上離れて 5 秒経過 → Patrol に戻る

### 難易度パラメータ（チューニング用）

| パラメータ | MVP デフォルト |
|---|---|
| フィールド半径（円フォールバック時） | 50m |
| アイテム数 | 5 |
| 鬼の数 | 1 |
| 鬼の patrol 速度 | 0.8 m/s |
| 鬼の chase 速度 | 1.0 m/s |
| アイテム回収距離 | **7m** |
| 鬼の発見距離 | **15m** |
| 鬼の捕獲距離 | **5m** |
| Return to patrol 距離 | 20m |
| 制限時間 | なし（オプション 5分） |

### 情報非対称性

- プレイヤーの画面: 鬼が「視界内（=スマホで方向を向いた時）」だけ AR で見える + 距離レベル感（近い/遠い）
- 鬼の正確な GPS 位置は地図に出さない（緊張感を出すため）
- アイテムは「半径 20m 以内に入ると方角インジケータ」だけ表示、それ以外は手探り

### 安全への配慮

ゲーム性より優先する設計判断:

- **道路グラフによる行動制約**: 鬼・アイテムとも `footway/path/pedestrian/residential` のみに乗せる。大通り（`primary`/`secondary`/`motorway`）は除外
- **GPS 誤差を吸収できる距離設定**: 回収 7m / 発見 15m / 捕獲 5m とし、5-10m の GPS 誤差より広く取る
- **フィールド推奨ルール**を README に明記: 車道・水場・私有地を含めない
- **ゲーム開始時の警告**: 「周囲の交通に注意」「画面を注視せず適宜顔を上げる」を毎回表示
- **道路グラフが取れないフィールド**: 鬼はランダム walk にフォールバックするが、その場合はゲーム開始時に「道路情報なし。周囲安全を確認してください」と追加警告

## 2. 技術スタック

### 採用

- **WebAR**: [8th Wall](https://8thwall.org/) オープンソース版
  - 雛形: [`8thwall/aframe-world-effects-example`](https://github.com/8thwall/aframe-world-effects-example)
  - SLAM: `@8thwall/engine-binary`（バイナリ配布、商用利用 OK）
- **3D**: A-Frame（雛形が A-Frame ベースのため）
- **位置取得**: `navigator.geolocation.watchPosition`
- **方角取得**: `DeviceOrientationEvent`（`absolute: true`）
- **地図データ**: [OpenStreetMap](https://www.openstreetmap.org/) / [Overpass API](https://overpass-api.de/)（API キー不要、無料）
- **永続化**: ローカルストレージ（プレイ履歴、設定、フィールド定義）
- **ホスティング**: GitHub Pages or Netlify（静的、HTTPS 必須）

### 8th Wall の他機能を後から使う

- **Image Targets**: 共通アンカーで GPS 誤差を吸収（ステージ開始時に基準マーカーをスキャン）
- **World Effects**: アイテム足元の魔法陣、捕獲エリアの可視化
- **Sky Effects**: 鬼接近時に空を暗く/赤く染める演出

優先度:
1. Image Targets（精度向上の本命）— Step 3 完了後に検証
2. World/Sky Effects（演出強化）— ゲームが動いてから

## 3. PoC ステップ

### Step 0: 雛形セットアップ
- `web/` ディレクトリに `aframe-world-effects-example` を取り込み
- `@8thwall/engine-binary` を依存追加、ライセンス notice を `LICENSE-XR.txt` として配置
- `npm run serve` → モバイル端末で HTTPS 経由カメラ起動確認

### Step 1: GPS + heading の取得・表示
- `navigator.geolocation.watchPosition` で位置取得（1Hz）
- Android Chrome の `DeviceOrientationEvent`（`absolute: true` のもの）で方角取得
- 画面オーバーレイに lat/lng/heading/精度 を表示

### Step 2: 仮想座標に AR アイテムを配置
- GPS→ローカル座標変換（lat/lng → meters）の関数を実装
  - 簡易式: `dx = (lng - lng0) * 111000 * cos(lat0)`, `dy = (lat - lat0) * 111000`
- 自分の位置から N メートル離れた点にお札（板ポリ + テクスチャ）を A-Frame で配置
- 7m 以内で表示、レチクル + タップで回収

### Step 3: フィールド + 道路グラフ + AI 鬼
- **フィールド定義 UI**: マップ画面でプレイヤーが頂点をタップして多角形を作成（最低 3 点）。実装が重ければ「中心 + 半径」の円でフォールバック可
- **OSM 道路グラフ取得**: フィールドの bounding box で Overpass API にクエリ（`way[highway~"^(footway|path|pedestrian|residential)$"]`）、node + edge のグラフを構築。失敗時はランダム walk にフォールバック
- **アイテム配置ロジック**: 道路グラフの edge 上から ±5m 範囲でランダムに N 個配置
- **鬼の状態マシン**実装（Patrol → Detect → Chase → Catch）。グラフ上の最短経路探索（Dijkstra で十分）
- **鬼の AR モデル表示**: MVP は赤いキューブ
- **発見・捕獲時の演出**: 画面エフェクト（サウンドは後回し）

### Step 4: ゲームループ統合
- スタート画面（フィールド設定、難易度選択）
- ゲーム開始時の安全警告ダイアログ（毎回必須表示）
- インゲーム HUD（残りアイテム数、鬼の方角インジケータ、スコア）
- クリア/ゲームオーバー画面
- リトライ・ステージ選択

### Step 5（オプション）: 精度向上と演出
- Image Targets で開始時座標合わせ
- World Effects でアイテム足元の演出
- Sky Effects で鬼接近時の空変化
- BGM / SE の追加（本体が完成に近づいてから）
